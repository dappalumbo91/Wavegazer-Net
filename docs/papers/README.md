# Source papers

Downloaded from arXiv as the local, citable baseline.

| File | Paper | Why it is here |
|------|-------|----------------|
| `1505.04597_unet.pdf` | Ronneberger, Fischer, Brox, MICCAI 2015 | The U-Net. Architecture, weighted CE, elastic augment, EM and cell-tracking numbers. |
| `1411.4038_fcn.pdf` | Long, Shelhamer, Darrell, CVPR 2015 | Fully convolutional predecessor. U-Net is an FCN with a symmetric decoder and concat skips. |
| `1606.06650_3d_unet.pdf` | Çiçek et al., MICCAI 2016 | Same U in 3D, sparse-slice training. |
| `1809.10486_nnunet.pdf` | Isensee et al., 2018 | How U-Nets are actually built and trained now. Vanilla U + automated pipeline. |

Nature Methods 2021 nnU-Net (Isensee, Jaeger, Kohl, Petersen, Maier-Hein) is the journal version of the last paper; the arXiv workshop draft is what we can pin without a paywall.
