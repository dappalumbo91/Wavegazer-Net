# Why this project is called Wavegazer Net

The working folder started as **Flow Net**. That name is already taken:
Dosovitskiy, Fischer, et al., *FlowNet: Learning Optical Flow with Convolutional
Networks* (ICCV 2015). It is a CNN for optical flow, not this project.

**Wavegazer Net** is the name of this FSOT visual U.

| Item | Value |
|------|--------|
| Project / folder | Wavegazer Net |
| Python package | `wavegazer` |
| Candidate network | `WavegazerNet` |
| Control network | `BaselineUNet` |
| Do not use | FlowNet, Flow Net, FlowUNet, `flownet` |

The optical-flow paper is unrelated. Do not cite it as prior art for this repo.
